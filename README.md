ANUDIP assignment 

1. Project Overview
The Car Sales Analysis project uses Microsoft Power BI to explore car sales data and present it through interactive reports.
The project dataset contains 5,000 sales records. It includes information such as sale date, customer, city, car brand, model, vehicle year, price, salesperson, and payment type.
The goal is to practise data analysis and reporting by working with a real-world-style sales dataset.
